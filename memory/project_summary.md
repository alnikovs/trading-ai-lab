# Project Summary: Trading AI Lab

This project integrates ChatGPT (strategic AI) with Cursor Cloud Agent (code executor)
through a custom orchestrator. ChatGPT plans development tasks, Cursor executes code
changes in a GitHub repository.

Main goals:
- Build a modular trading bot integrating Hyperliquid and later 3Commas and CEXs.
- Integrate Allora forecasts and LLM reasoning into strategies.
- Automate code generation and PR creation via Cursor Cloud Agent.
- Maintain clean architecture: core/, exchanges/, strategies/, risk/, utils/.
